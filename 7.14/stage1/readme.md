# 第一阶段：标注聚簇与结构挂接

第一阶段解决矿井图纸上的标注语义问题：将测点（控制点）、钻孔等由符号与文字组成的组合识别为语义簇，再将簇与剩余巷道名称挂接到巷道中心线结构图。实现分为甲、乙两步，代码分别位于 `step1a/` 与 `step1b/`。操作命令与磁盘路径见各目录说明；仓库级进度见 [`docs/01-architecture.md`](../docs/01-architecture.md)。本文只说明计算逻辑与设计动机。

阈值分别集中在各目录顶层配置文件中。图纸须先经 `utils/entity_export.py` 导出为根目录 JSON；甲步不再直接读图纸。

## 数据流概要

| 步骤 | 主要输入 | 主要输出 |
|------|----------|----------|
| 第一阶段甲 | 文字 JSON、图例 JSON；整图标定得到的图例模板与识别规则 | 最终簇图 |
| 第一阶段乙 | 巷道中心线结构图；最终簇图 | 带标注的结构图 |

说明：按《重要原则》第 7 条，完整步骤宜「只输入一个逻辑拓扑图、只输出一个逻辑拓扑图」。当前甲步起点为导出 JSON，乙步同时读入结构图与最终簇图，与该条尚有差距；下文按现行实现描述。

## 为何拆成甲、乙两步

1. **标注语义与几何拓扑解耦**：聚簇只依赖图纸标注与图例；挂接只依赖已有中心线结构图。两侧可独立重跑、独立更换数据源。
2. **整图标定、局部复用**：识别规则由图例与整图共现统计得到，局部图不必另行猜测图层含义。
3. **尺度自适应**：长度类阈值多取字高中位数或巷道宽度中位数的倍数，避免在图纸坐标中写死绝对距离。

## 第一阶段甲：由图例归纳规则并识别聚簇

### 总流程

```text
【整图】
  导出文字 JSON、图例 JSON
  脚本0  建立标注关系图（含测点字值绑定链，选圆前暂停）
  脚本1  从图例 JSON 归纳图例模板
  脚本2  用整图共现标定识别规则（图层到角色、搜索半径）
  脚本3  套用规则，得到候选簇图
  脚本4  按得分独占过滤，得到最终簇图

【局部图】
  导出局部文字 JSON
  脚本0  建立局部标注关系图
  脚本3  套用整图规则，得到候选簇图
  脚本4  得到最终簇图
```

整图负责归纳形态与本图图层语义；局部图按同一规则查找实例。更换图系列时，更新图例并重跑脚本 1、2 即可。

### 脚本 0：标注关系图与测点字值绑定链

1. 从文字导出 JSON 提取文字、多行文字、圆、块参照，建成标注节点图。
2. 按字高中位数缩放半径，加入邻接边、文字邻近边、朝向一致边、以及控制点图层族上的字与值绑定边（在选圆之前建立）。
3. 绘制建链核对图后暂停，此时尚未将文字栈挂到圆上。

设计动机：先固定同一测点文字栈，再一对一挂圆；邻接边限定候选范围；中间产物可核对。

### 脚本 1：从图例归纳模板

仅在「图例」图层导出记录中：用标题文字识别控制点或钻孔种子，在近旁选取符号（测点优先圆，钻孔优先块参照），再采集字段样例，合并为模板。形态来自图纸自身图例，而非写死绝对圆半径。

### 脚本 2：整图共现标定识别规则

在排除图例层的整图上：按模板寻找锚点，在投票半径内统计图层到角色的映射；用命中距离的高分位数得到搜索半径。图例约束形态，整图投票给出本图图层语义。

### 脚本 3：套用规则生成候选簇图

- **角色**：优先采用规则中的图层映射，并以文字形态校验。
- **测点**：每个绑定组与圆一对一就近分配；多组争夺同一圆时，较远组改挂次近空闲圆。
- **钻孔**：以块或圆为锚，沿邻接边在搜索半径内收录成员；距离分两阶衰减打分。
- **打分**：图层匹配、距离、朝向加权；簇置信度为成员得分均值。

候选阶段允许多归属，避免过早独占截断正确组合。

### 脚本 4：候选簇图到最终簇图

按成员总分做独占归属；丢弃无标号或低置信度簇，但其成员尽量迁入幸存簇；吸收近距且同文的孤立孔号或测点号；簇重新编号后写出最终簇图。候选阶段求召回，最终阶段求独占。

### 甲步设计要点

| 要点 | 体现 |
|------|------|
| 尺度自适应 | 邻接、绑定、投票、搜索半径均相对字高中位数 |
| 先关系后归属 | 绑定栈 → 多对多候选 → 得分独占 |
| 整图标定、局部套用 | 图例模板与识别规则与目标图解耦 |
| 图例驱动可迁移 | 减少按图硬编码图层表 |
| 产物一名一义 | 标注关系图 → 候选簇图 → 最终簇图 |

产物对照与已运行命令见 `step1a/readme.md`。整图最终簇已落盘（约 958 簇）。

## 第一阶段乙：簇与巷道名称挂接到中心线

### 脚本 0：生成带标注的结构图

1. 复制调用方传入的巷道中心线结构图。
2. 读入甲步产出的最终簇图。
3. 由点到中心线距离统计推断挂接阈值。
4. 将簇节点及其成员边并入图；垂足距离不超过阈值时增加挂接边。
5. 未入簇的文字一律视为巷道名称，同样尝试挂接。

### 脚本 1：可视化核对

绘制中心线、簇、巷道名称与挂接边。整图与局部图带标注结构图均已落盘；命令见 `step1b/readme.md`。

## 甲、乙衔接

甲步只产出语义簇，不修改巷道几何。乙步不重新分类测点与钻孔，只做空间挂接。后续阶段应消费带标注的结构图。第二阶段在此基础上挂接通风设施，见 `stage2/readme.md`。

本目录下 `nodes.py`、`proximity_edges.py`、`parallel_edges.py` 等为早期邻接实验，不参与现行主数据流。
