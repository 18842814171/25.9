# 公共工具

本目录存放第一阶段与第二阶段共用的模块。阶段专属阈值与产物路径仍在各阶段顶层配置中。仓库级架构见 [`docs/01-architecture.md`](../docs/01-architecture.md)。

## 图纸图元导出

| 文件 | 作用 |
|------|------|
| `entity_export_config.json` | 导出配置：图纸路径、mode、各 mode 的 `layers` / `exclude_layer_keywords` 与 `output_filename` |
| `entity_export.py` | 本仓库唯一直接读取图纸文件的入口；写出根目录 JSON |
| `indep_json.py` | 各图元类型 attributes 序列化 |
| `entities_filter.py` | 按类型、图层子串筛选；再按排除关键词去掉图层 |
| `entity_json.py` | 读取已导出 JSON，并转为各阶段建图用记录 |
| `fix_export_positions.py` | 将异常块参照的插入点改为变换后包围盒中心 |

## 其它共用模块

| 模块 | 作用 |
|------|------|
| `paths.py` | 仓库根路径、相对路径解析 |
| `graph_io.py` | 拓扑图读写公共辅助；阶段可读格式由各阶段图读写模块传入 |
| `attach_geometry.py` | 点到线段距离、最近中心线 |
| `attach_centerlines.py` | 中心线目录、关联距离阈值推断 |
| `text_clean.py` | 文字清洗、多行文字明文 |
| `stats.py` | 字高中位数等统计 |
| `plot_font.py` | 核对图中文字体设置 |

## 已运行命令

在仓库根目录；用 `--cfg` 传入配置，再按 mode 导出。配置中 `layers` 为子串（如 `"巷道"`），图层名包含该子串即导出；可选 `exclude_layer_keywords` 再去掉名称含这些词的图层（例如 `layers` 含「巷」时用 `"辅巷"` 排除辅巷相关层）。下列命令已用于生成当前根目录导出文件：

```text
python utils/entity_export.py --cfg utils/entity_export_config.json --mode text
python utils/entity_export.py --cfg utils/entity_export_config.json --mode line
python utils/entity_export.py --cfg utils/entity_export_config.json --mode facility
python utils/entity_export.py --cfg utils/entity_export_config.json --mode legend
```

若文字导出中有插入点飞到图外的块参照，可再执行：

```text
python utils/fix_export_positions.py --mode text
```

产物写在仓库根目录，文件名由配置中的 `output_filename` 决定（分别为 `{图号}-文字.json`、`{图号}-巷道.json`、`{图号}-设施.json`、`{图号}-图例.json`）。图例一次抽出后，第一阶段甲与第二阶段的模板脚本按需读取；各阶段建图脚本只读这些 JSON，不再读图纸。
